# Contributing

- Work on a branch and open a pull request; `main` is published automatically.
- One chapter (or one topic) per PR keeps reviews manageable.
- Don't reflow paragraphs you didn't change — it hides real edits in diffs.
  Writing one sentence per line is encouraged.
- Follow the conventions in [`CLAUDE.md`](CLAUDE.md) (notation, cross-reference
  labels, one language per chapter, seeds for simulations).
- Make sure `quarto render <your chapter>` succeeds before requesting review;
  CI will render the whole book on your PR.
- Small fixes (typos, wording) can be made directly on GitHub via the
  "Edit this page" link in the published book.
